# 3. 프로젝트 개요

## 📕 프로젝트명
전기차 현황 및 충전 인프라 분석 대시보드

## ✅ 프로젝트 배경 및 목적
전기차 및 하이브리드 차량 보급이 빠르게 증가함에 따라  
지역별·연도별 전기차 등록 현황과 충전 인프라의 불균형 문제가 대두되고 있다.  

본 프로젝트는 **전기차/하이브리드 등록 현황**, **전국 충전소 분포**,  
**지역별 차량 대비 충전 인프라 현황**을 한눈에 확인할 수 있는  
대시보드를 구축하여, 데이터 기반 인사이트를 제공하는 것을 목적으로 한다.

## 🖐️ 프로젝트 소개
본 프로젝트는 Streamlit 기반의 웹 대시보드로,  
다음과 같은 기능을 제공한다.

- 지역별·연도별·브랜드별 전기차/하이브리드 등록 현황 시각화
- 전국 전기차 충전소 지도 시각화
- 지역별 차량 대비 충전 인프라 비교 분석
- 현대/기아 전기차 모델 정보 제공
- 브랜드별 FAQ 기능 제공

사용자는 복잡한 데이터 분석 없이도  
전기차 보급 현황과 충전 인프라의 지역적 차이를 직관적으로 파악할 수 있다.

## ❤️ 기대효과
- 충전 인프라가 부족한 지역을 데이터 기반으로 확인 가능
- 전기차 구매 예정자에게 유용한 정보 제공
- 정책·마케팅·기획 관점에서 활용 가능한 기초 데이터 제공

## 👤 대상 사용자
- 전기차 및 하이브리드 차량 구매를 고려하는 일반 사용자
- 전기차 충전 인프라 현황을 파악하고 싶은 사용자
- 전기차 관련 데이터 분석 및 시각화에 관심 있는 입문자
- 친환경 자동차 정책 및 시장 동향을 분석하는 기획자
